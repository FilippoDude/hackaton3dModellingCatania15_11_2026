Per scaricare le dipendenze:

```
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Poi entrando dentro a una delle cartelle si può eseguire lo script:

```
python main.py
```

Fondamentale fornire la path degli eseguibili forniti durante la prova: `mi_convert`, `mi_process`.

> Assicurarsi che gli eseguibili abbiano i permessi di esecuzione
